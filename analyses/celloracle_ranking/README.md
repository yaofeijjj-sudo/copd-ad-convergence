## 2. delta_X 的尺度：原图的“相对变化 %”单位写错了

**证据**：
- 本项目代码 `rebuild.py`：先按细胞标准化（`normalize_per_cell`）。
- CellOracle 0.20.0 的 `import_anndata_as_raw_count`：默认 `transform = "natural_log"`，即 log1p，结果存入 `normalized_count`。
- `knn_imputation` 在这个对数空间中插补，得到 `imputed_count`；`simulate_shift` 以它为输入，输出 `delta_X`（`simulate.py` 读取的正是这两层）。

因此，delta_X 是 ln(1 + 标准化表达) 上的差值，相当于 ln[(1 + x_模拟) / (1 + x_基线)]，是一个有符号的对数比值。原图 6d–f 的 `100 × delta_X / 基线` 是“对数值的百分比变化”，不是表达量的百分比变化。

**影响有多大**（[Fig6def_source_signed_logratio.tsv](results/Fig6def_source_signed_logratio.tsv)）：
- 换成线性尺度的真实百分比变化后，STAT3、CEBPB、LYL1 各基因的排序几乎不变（Spearman 0.98–1.00），方向完全不变。
- 肺侧原图数值的绝对值约为线性百分比的 0.7–0.8 倍（中位数）。

结论：图的形状和结论不变，只是单位标错了。

**建议改法**：图 6d–f 的坐标改为有符号的 delta_X，标注为“预测表达变化（ln 尺度）”；或者直接用线性百分比，两列都已给出。图 6b 继续用器官内响应百分位（表中已给出肺、脑的百分位）。
